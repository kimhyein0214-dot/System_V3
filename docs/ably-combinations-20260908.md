# 에이블리 조합관리로 방향 전환

사용자 요청에 따라 날짜별 주문 연동과 추가 재고 차감 개발을 취소했다. 주문수집은 기존 과정에서 처리하고, 이후 갱신한 개별 SKU 재고의 최솟값을 조합형 재고로 사용하는 방향으로 변경했다. 기존 조합형 재고는 계산에서 제외한다.

Q열 옵션관리코드를 개별 셀피아 SKU 연결 메모로 사용한다. SKU1/SKU2 또는 [SKU1],[SKU2] 형식을 지원하며 R열 조합 SKU는 그대로 둔다. Q열이 비어 있으면 미등록으로 표시한다. 현재 샘플은 옵션기본 35컬럼/90행이며 Q열은 모두 비어 있다.

이번 변경 범위는 전용 탭, 계산 기준/35컬럼 안내, 브라우저 내 Q열 연결값 파일 미리보기다. 개별 SKU 재고 조회와 계산값 저장/출력은 아직 구현하지 않았다. 사용자 파일의 상품/계정/연결 데이터는 정적 배포에 포함하지 않는다.

이전 주문 연동의 공개 및 private 진입 함수 권한을 취소하는 마이그레이션을 적용한다. 기존 테이블/이력은 삭제하지 않는다. 이전 화면과 데이터 서비스의 주문 연동 진입점도 제거했다. 피킹 코드와 스크래퍼는 수정하지 않았다.

검증: 관련 mock 테스트 79개 통과. 브라우저에서 실제 첨부 파일을 읽어 조합형 90행 / 연결값 0 / 미등록 90 / 형식 오류 0을 확인했다. DB의 이전 주문 연동 공개 함수 4개의 anon/authenticated 실행권한은 모두 false이며 작업/재고원장은 각각 0건이다.

취소 마이그레이션 파일 시각 20260908082306은 원격 이력 20260908082517(cancel_order_stock_integration)에 대응한다.

## 가상 상품과 상품별 하위 화면

추가 요청에 따라 첫 화면은 D열 온라인 상품명을 제목으로 한 상품 목록으로 변경했다. 상품을 선택하면 해당 상품의 조합 옵션만 하위 화면에 표시하며 목록으로 돌아갈 수 있다. 제목이 같아도 계정/판매자관리코드가 다른 상품은 합치지 않는다. 200개를 넘으면 더 보기로 이어서 확인한다.

가상 테스트 상품 1000에는 개별 SKU 1000-1부터 1000-10까지와 조합 4개를 준비했다. 초기 계산값은 1000-1+2=12, 1000-3+4+5=8, 1000-6+7+8=0, 1000-9+10=7이다. Q열 연결과 개별 재고, 기존 가상 조합 재고를 편집할 수 있다. 가상 재고 갱신은 최솟값을 가상 W값으로 반영한다. 기존 조합 재고 초기값 999는 계산에 사용하지 않는다.

가상 상태는 별도 localStorage 키 operations-hub-ably-virtual-lab-v1에만 저장하며 운영 DB나 외부 판매처에 쓰지 않는다. 테스트 초기화로 복구한다. 재고 누락, 음수/소수, 연결 형식 오류는 해당 조합을 제외하며 실제 0은 유효하다.

브라우저에서 첨부 파일의 상품 1개 → 하위 옵션 90행 탐색과 1000-2 재고 변경(12→5) → 조합 1000-1+2 가상 재고 갱신(999→5), 품절 조합 0 반영을 확인했다.
